CPF File Upload Component - Comprehensive Demo

Explore all features and use cases of the file upload component

1. Basic File Upload

Default configuration with drag & drop support and multiple file selection.

2. Single File Upload

Only one file can be uploaded. Uploading a new file replaces the existing one.

3. Multiple Files Upload

Upload multiple files simultaneously using drag & drop or file selection.

4. Restricted File Types

Only specific file types are allowed (PDF, JPG, PNG, GIF).

5. Required File Upload

This field is required with validation support.

6. Large Upload Area

Larger drop zone for enhanced user experience.

7. Readonly Upload (View Only)

Files are displayed but cannot be uploaded, modified, or removed.

8. Disabled Upload

Upload functionality is completely disabled.

9. Upload with Warning State

Shows a warning message to inform users about constraints.

10. Upload with Error State

Displays error messages for validation failures.

11. Custom Width Upload

Upload component with custom width (50%).

12. Upload without Base64 Encoding

Files are stored as File objects instead of base64 encoded strings.

API Documentation

Input Properties

Property Type Default Description
config IExtendedFieldConfig - Configuration object for the file upload component
encode boolean true Whether to encode files in base64 format

Output Events

Event Type Description
change EventEmitter<any> Emitted when the file list changes
remove EventEmitter<any> Emitted when a file is removed

IExtendedFieldConfig Interface

Property Type Description
label string Label text for the upload field
required boolean Whether the field is required
showHelpIcon boolean Show help icon next to label
helpContent string Help tooltip content
showError boolean Show error/warning state
errorText string Error/Warning message text
warning boolean Display as warning instead of error
noteText string Helper text below the upload area
editable boolean Whether files can be edited/removed
disabled boolean Disable the upload component
readonly boolean Display in readonly mode
isLarge boolean Use larger upload area
multiselect boolean Allow multiple file selection
base64Encode boolean Encode files in base64 format
controlWidth string Custom width for the control (CSS value)
extraProperties object Additional properties (e.g., allowedfiletypes)
