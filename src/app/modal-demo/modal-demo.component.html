API Reference

Method Parameters Description
alertDanger() IModalAlertParams Shows danger alert with red icon
alertWarning() IModalAlertParams Shows warning alert with yellow icon
alert() IModalAlertParams Shows standard alert
info() IModalAlertParams Shows info modal with optional cancel
error() IModalAlertParams Shows error modal with details
warning() IModalAlertParams Shows warning modal with cancel option
loading() msg: string, params?: ModalOptions Shows loading spinner
confirm() msg, confirmCb, cancelCb, title?, labels?, icon? Shows confirmation dialog
success() msg, confirmCb, cancelCb?, title?, labels?, showClose? Shows success notification
modalComponent() component, confirmCb, cancelCb?, params? Shows custom component in modal
modalTemplate() template: TemplateRef, params? Shows custom template in modal
